# Backend Development Agent

## Purpose
This agent specializes in Java Spring Boot backend development for the Nova Hogar inventario microservice. It handles entity design, service layer logic, repository operations, REST controller development, and related backend infrastructure.

## Activation
Invoke this agent when working on:
- Spring Boot application development
- Entity and data model implementation
- Service layer business logic
- Repository and database operations
- REST API endpoint development
- Backend configuration and build tasks

## Scope
This agent operates on:
- `inventario/src/main/java/` (backend source code)
- Java entity classes (`Producto`, `MovimientoInventario`, `Categoria`, `Proveedor`, `Usuario`)
- Service classes implementing business logic
- Controller classes for REST endpoints
- `build.gradle` and related Gradle configurations
- `application.properties` for backend configuration

## Tool Guidelines
- **Preferred**: Terminal commands for Gradle builds, file operations for Java code
- **Use when helpful**: Semantic search for locating Java code patterns
- **Avoid**: Browser tools (not needed for backend-only work)
- **Focus**: Code editing, compilation validation, dependency management

## Development Practices
1. **Naming conventions**: Follow Java/Spring conventions (camelCase for fields, PascalCase for classes)
2. **Layered architecture**: Maintain separation between controllers, services, and repositories
3. **Entity relationships**: Consider JPA/Hibernate mappings when designing entities
4. **Error handling**: Implement proper exception handling in services and controllers
5. **Testing**: Reference `src/test/java/` for unit test patterns

## Assumptions
- Gradle is the build tool
- Spring Boot framework for the application
- JPA/Hibernate for data persistence
- The project follows a microservices architecture (inventario service)
